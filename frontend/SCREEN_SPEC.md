# 화면 구성

> 기준: 첨부된 `src(5).zip`의 현재 React 프론트엔드 구현 및 `App.js` 라우팅
>
> 이 문서는 기존 화면 구성 문서를 현재 프론트엔드에 맞게 수정한 버전입니다.

---

## 0. 공통 레이아웃 및 라우팅

### 0.1 공통 헤더

로그인, 회원가입, 아이디 찾기, 비밀번호 찾기 화면을 제외한 주요 화면에서 공통 헤더를 사용합니다.

#### 헤더 표시 정보

- 로고
- 룸메찾기
- 커뮤니티
- 채팅
- 캘린더
- 계정 영역

#### 비로그인 상태

- 로그인 버튼 표시
- 로그인 버튼 클릭 시 로그인 화면으로 이동

#### 로그인 상태

- 사용자 아바타
- 사용자 이름
- 프로필 메뉴 열기/닫기
- 마이페이지 이동
- 로그아웃

### 0.2 주요 라우팅

- `/` : 메인페이지
- `/roommates` : 룸메찾기
- `/roommates/:profileId` : 상세 프로필 모달
- `/community` : 커뮤니티
- `/community/posts/new` : 게시글 작성
- `/community/posts/:postId` : 게시글 상세
- `/community/posts/:postId/edit` : 게시글 수정
- `/community/my-posts` : 내가 작성한 게시글
- `/community/my-comments` : 내가 작성한 댓글
- `/chat` : 채팅
- `/calendar` : 캘린더
- `/profile` : 마이페이지
- `/profile?tab=survey` : 내 설문
- `/profile?tab=preferences` : 선호 룸메 설문
- `/profile?tab=likes` : 좋아요
- `/profile?tab=account` : 계정 정보
- `/admin` : 관리자 페이지
- `/login` : 로그인
- `/signup` : 회원가입
- `/find-id` : 아이디 찾기
- `/find-password` : 비밀번호 찾기

### 0.3 설문 관련 리다이렉트

- `/profile-survey` 접근 시 `/profile?tab=survey`로 이동
- `/roommate-preference-survey` 접근 시 `/profile?tab=preferences`로 이동

## 2.4 비밀번호 찾기

### 1단계 계정 확인

- 아이디 입력
- 가입 이메일 입력
- 비밀번호 재설정 이메일 전송

### 2단계 이메일 전송 완료

- 입력한 이메일 표시 및 가입 정보가 일치하면 메일이 전송된다는 안내
- 이메일 재입력
- 비밀번호 재설정 단계 이동

### 3단계 새 비밀번호 설정

- 메일로 받은 재설정 토큰 입력
- 새 비밀번호
- 새 비밀번호 확인
- 8자 이상 확인
- 비밀번호 일치 여부 확인
- 서버에서 토큰 검증 및 비밀번호 변경, 실패 시 오류 안내

### 4단계 완료

- 비밀번호 변경 완료 상태 표시
- 로그인 화면으로 이동

# 12. 현재 프론트엔드 구현 기준 확인사항

## 12.1 설문 라우팅

- `ProfileSurveyPage.js`와 `PreferenceSurveyPage.js` 파일이 존재하지만 현재 `App.js`에서는 직접 렌더링하지 않습니다.
- 실제 사용자 화면은 마이페이지의 `내 설문`, `선호 룸메 설문` 탭입니다.

## 12.2 선호 룸메 필수조건

- `PreferenceSurveyPage.js`에는 `필수조건 설정` 단계가 정의되어 있습니다.
- 하지만 현재 실제 라우팅에서 사용하는 마이페이지의 선호 룸메 설문에는 필수조건 설정 영역이 없습니다.
- 현재 활성 화면 기준으로는 항목별 중요도 1~5 설정만 존재합니다.

## 12.3 생활관 명칭 불일치

현재 프론트 코드에서 생활관 명칭이 화면별로 다릅니다.

- 회원가입: `비룡`
- 마이페이지 계정 정보: `비봉`
- 커뮤니티 및 일부 프로필 데이터: `비봉관`

백엔드 연동 전 하나의 명칭으로 통일할 필요가 있습니다.

## 12.4 상세 프로필 설문 항목 불일치

상세 프로필에는 다음 항목이 존재하지만 현재 마이페이지의 `내 설문`에서는 직접 입력하지 않습니다.

- 방 안에서 드라이기 사용
- 벌레

백엔드 설계 전에 실제 설문 항목으로 유지할지 제거할지 정리가 필요합니다.

## 12.5 룸메찾기 검색

- 기존 문서의 텍스트 검색창은 현재 구현되어 있지 않습니다.
- 현재 룸메찾기는 설문 항목 기반 필터를 사용합니다.

## 12.6 채팅 분류

현재 채팅 분류는 다음 3개입니다.

- 전체
- 룸메찾기
- 커뮤니티

기존 문서에 있던 `기숙사` 채팅 분류는 현재 구현되어 있지 않습니다.

## 12.7 프로필 카드 태그

- 프로필 데이터에는 태그가 존재합니다.
- 현재 룸메찾기 프로필 카드 UI에는 태그가 직접 표시되지 않습니다.
- 상세 채팅 프로필에서는 태그를 표시합니다.
