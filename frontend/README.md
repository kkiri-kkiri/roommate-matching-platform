## 페이지 파일 구조

각 페이지는 다음 구조를 사용합니다.

```text
PageName.js
PageNameCss.js
```

- `PageName.js`
  - 화면 마크업
  - 더미 데이터
  - UI 확인에 필요한 최소한의 로컬 상태
  - 탭 전환, 모달 열기 등 프론트 UI 동작

- `PageNameCss.js`
  - 해당 페이지 전용 styled-components
  - 반응형 스타일
  - 입력창, 버튼, 카드, 테이블 등의 디자인
