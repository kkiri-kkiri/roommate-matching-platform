# 게시글 이미지 접근 제어 및 정리 작업 배포

`20261019_post_image_cleanup.sql`은 수동 적용용이다. 이 작업에서는 DB에 적용하지 않았다.
기본/prod `ddl-auto=validate`, `spring.sql.init.mode=never`를 유지한다.

1. 백업과 복구 계획을 확인하고 실제 테이블 대소문자·InnoDB·문자셋/Collation을 점검한다.
   `POST_IMAGE_CLEANUP` 신규 테이블 및 `POST_IMAGE.image_url` 비고유 인덱스를 검토한다.
   기존 동등 인덱스와 중복 적용을 피한다. VARCHAR(500) 인덱스의 바이트 한도와
   실제 EXPLAIN, DDL 잠금·부하·권한은 별도 격리 MySQL에서 검증한다.
2. 운영자가 승인된 절차로 DDL을 먼저 수동 적용한 뒤 애플리케이션을 배포한다.
   대기 작업에는 FK가 없다. `image_url`은 삭제 대상 식별자이며 다른 데이터의 삭제 명령이 아니다.
   초기 테이블은 비어 있다. 과거 파일이나 DB를 스캔·삭제·변환하지 않는다.
3. 기존 정적 리소스를 제공하는 모든 구버전 서버의 트래픽을 종료한다. 프록시/CDN/웹서버의
   업로드 폴더 alias, 별도 공개 버킷/볼륨 노출이 있다면 제거한다. 이미지 GET은 항상
   새 백엔드에 전달하고 캐시를 우회한다. 기존 CDN 캐시는 운영자가 무효화해야 한다.
4. `app.community.image-directory`는 영속적인 비공개 업로드 폴더다(기본 `uploads/community`).
   작업자가 같은 DB의 모든 파일에 접근할 수 있도록 모든 인스턴스에 같은 저장소를 연결한다.
   로컬 디스크가 서로 다르면 다른 노드에서 파일이 없다는 이유로 작업을 완료할 수 있으므로
   다중 노드에 이 구조를 그대로 배포하면 안 된다. 현재 저장소에는 Docker/compose/프록시 설정이 없다.
   실제 볼륨·재시작 후 지속성·권한·백업은 운영 구성에서 확인한다. 디렉터리와 부모는 신뢰된 운영자만
   수정해야 하며 다른 사용자에게 링크/디렉터리 교체 권한을 주지 않는다.
5. `app.community.image-cleanup.enabled=true`가 기본이다. 커밋 후 즉시 한 번 처리하고,
   스케줄러가 기본 60초 간격으로 기한이 지난 작업을 최대 100개 재시도한다.
   `app.community.image-cleanup.delay-ms`로 간격을 설정한다. 실패 작업은 1분 뒤 재시도한다.
   test 프로필은 스케줄을 끄고 명시적으로 실행한다. Gradle 테스트는 임시 기본 저장 루트와
   스케줄 비활성화를 JVM 속성으로 강제한다. 자동 정리는 새로 기록된 개별 제거 작업만 대상이다.
6. `POST_IMAGE_CLEANUP`의 오래된 `created_at`, `attempts`, `next_attempt_at` 및 jobId 로그로
   적체를 감시한다. DB·저장소 장애나 잘못된 식별자는 행을 보존한다. 파일명·내부 경로·예외 원문은
   정리 로그에 남기지 않는다. 권한/마운트를 복구하면 재시도된다. 임의로 작업을 성공 처리하지 않는다.
   동기 커밋 후 처리에는 별도 DB 연결과 파일 I/O가 필요하므로 동시 쓰기 수에 맞춰 풀 용량과
   연결/저장소 시간 제한을 검증한다. 저장소 I/O 지연의 엄격한 요청 시간 상한은 제공하지 않는다.
7. 롤백 시 신규 테이블/작업을 보존한다. 구버전의 정적 공개 경로를 되살리면 취약점이 재발한다.
   파일 삭제 뒤 작업 완료 커밋 전에 종료되어도 행이 남고, 재시도에서 없는 파일은 성공 처리된다.
   삭제 게시글의 이미지 연결과 파일은 남기며 정리 작업을 만들지 않는다. 보존 기간·관리자 복구/
   열람 API는 새로 구현하지 않는다. 과거 고아 파일 정리는 백업·대상 검토·별도 승인 이후의 작업이다.

실제 MySQL, 다중 JVM, 공유 저장소, 강제 프로세스 종료와 CDN 검증은 별도로 필요하다.
테스트의 새 worker/storage 객체 재생성 및 강제 예외는 재시작 실패 구간의 모사이며 실제 재부팅 검증이 아니다.
