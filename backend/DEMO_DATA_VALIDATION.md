## 일반 BackendApplication의 실제 API

전시회 실행기를 사용하지 않고 `com.kkirikkiri.BackendApplication`을 일반 main class로 실행했다.
대상은 확장 검증 DB, 전용 로컬 포트 18082, local/NONE/validate/SQL never였다.
수집/이미지 정리를 비활성화하고 임시 로컬 JWT로 인증 조회만 했다. 토큰/키는 출력하거나 저장하지 않았다.

- 공개 룸메이트 목록: 50명.
- 공개 게시글 목록: 80개.
- 신규 일반 31번 회원: 최신 닉네임 반환, 생활 설문 completed=true, 선호 completed=true.
- 해당 회원의 인증된 매칭 목록: 본인 제외 49명.
- 신규 회원 채팅방: 0개, 기존 일반 1번 회원 채팅방: 기존 2개.
- 8개 성공 조회 후 다시 영수증 보존 검사를 통과했다. 조회수/읽음을 바꾸는 상세·메시지 조회는 하지 않았다.
- 임시 서버는 해당 PID·main class·전용 포트·시작 시각을 확인해 종료했다. 기존 서버를 종료하지 않았다.
